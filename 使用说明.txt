Antigravity 中文汉化补丁 v3.6 使用说明
======================================

适用范围
--------
- 适用于 Windows 版 Google Antigravity 桌面端（已全面适配并验证至 2.26.0 及后续版本）。
- 默认支持安装路径：
  %LOCALAPPDATA%\Programs\antigravity（原生支持跨盘 mklink /J 目录联接自动识别与更新后恢复）

核心亮点
--------
1. 全量深度汉化：涵盖主界面、设置、权限、模型与额度、全部输入框占位符、远程控制 (Remote Control / Connected Apps)、云端工作区资源、插件市场全量分类与插件说明、添加 MCP 服务弹窗全部 98 个可选 MCP 服务说明与 107 项参数配置、351 项本地内置技能与 MCP 子工具说明、WSL 连接与部署、系统托盘及原生右键菜单（5470+ 条精确词条 + 560+ 动态正则）。
2. 软件内自动更新与跨盘联接 100% 自愈：内置同步串行更新事务代理（update_runner.vbs）与后台守护服务（auto_heal.vbs）。无论通过软件内“重启以更新”还是官网安装包覆盖更新，均会自动静默完成安装、恢复跨盘 mklink /J 目录联接并注入中文补丁后再启动新版客户端。
3. 极速内存级安装：无需解压上百个临时文件，50 毫秒即可完成安装，支持在软件运行期间执行安装并自动避让文件锁。

安装方法
--------
1. 将压缩包完整解压到任意文件夹（请勿直接在压缩包预览窗口中双击运行）。
2. 双击运行“install_patch.bat”。
3. 窗口显示“✓ 汉化补丁 v3.6 安装成功！”后，重新启动 Antigravity 即可看到完整中文界面。

卸载及恢复英文
--------------
1. 双击运行“uninstall_patch.bat”。
2. 脚本会自动清理后台自愈服务并将程序恢复为英文原版。
3. 重新启动 Antigravity 即可恢复英文界面。

常见问题
--------
- 提示找不到 Antigravity：请确认软件安装在默认目录 %LOCALAPPDATA%\Programs\antigravity。
- 本补丁自带运行时调用逻辑，不需要电脑额外安装 Node.js。
- 代码编辑器（Monaco）与终端（Xterm）中的代码、命令和模型名称已做严格保护，不会被翻译破坏。
